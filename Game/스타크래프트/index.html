이 순서로 실험해 보세요

① 저글링(4) 선택 → 피격(H). 체력은 35에서 20이 된 뒤 같은 턴에 2 회복되어 22가 됩니다. 다음 턴(N)을 누르면 24가 됩니다.

② 레이스(2)의 은신(S), 저글링(4)의 잠복(S)을 켠 다음 탐지(D)를 누르세요. 옵저버가 거리 제한 없이 두 유닛을 탐지합니다.

③ 옵저버(5)를 피격시키면 체력보다 쉴드가 먼저 줄고, 턴 끝에 쉴드가 3 회복됩니다. 테란은 자동 회복하지 않습니다.

  • M: 좌표 X와 Y를 각각 1 증가
  • S: SCV 채취 / 레이스 은신 / 저글링 잠복 / 드랍쉽 탑승·하차 / 옵저버 영구 은신 확인
  • D: 선택 유닛과 관계없이 생존한 옵저버가 탐지
  • 1–5: 선택만 변경, Q: 정지·재개 (턴 소모 없음)

C# 구조가 JavaScript로 바뀌는 방법

Unit은 체력·이동·피격의 공통 설계입니다. TerranUnit / ZergUnit / ProtossUnit이 이를 상속하고, 다섯 유닛 클래스가 고유 능력을 더합니다.

updateTrait()를 모든 유닛에 똑같이 호출해도, 저그는 체력, 프로토스는 쉴드를 회복합니다. 같은 호출이 서로 다르게 동작하는 것이 다형성입니다.

JavaScript에는 C#의 인터페이스 문법이 없어서 gatherResource, toggleCloak 같은 메서드의 존재로 능력을 확인합니다. 파일 안에 한국어 설명 주석을 넣었습니다.

원본 규칙: 최대 체력 60 / 120 / 150 / 35 / 40, 옵저버 쉴드 20. 실패한 능력·이동 명령도 턴이 흐릅니다. 탐지는 실행 시점의 결과이며 다음 명령까지 강조됩니다.

웹 버전 보완: 중복 탑승, 잠복 중 탑승, 파괴 유닛의 행동을 방지합니다. 탑승자는 수송선을 따라 이동하고 하차 시 같은 좌표에 놓입니다. 수송선이 파괴되면 탑승자도 파괴됩니다. 정원은 원본처럼 8기이며 거리 제한은 없습니다.
